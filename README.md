# PlanBot · Botathon 2026 · Equipo 33

Planificación asistencial automatizada para Teletón ("Cada hora cuenta").

- **Blue Prism** recibe y valida los Excel (base de contratos y planilla de planificación).
- **PostgreSQL** guarda las reglas y calcula, por profesional y mes, horas, atenciones, meta (90 %) y % FOJA.
- **Dashboard** HTML + JavaScript muestra el consolidado nacional con filtros.

Instrucciones para agentes de IA: `AGENTS.md`. Contratos: `docs/contratos.md`. Reglas: `docs/reglas.md`.
Instalación y demo: se completa en la historia D-08.
